## 🎯 מה זה Qboard ומה המערכת עושה? (What is Qboard?)

**Qboard** (שילוב של **Quality** + **Quick** + **Whiteboard**) היא תוכנת שולחן-עבודה חדשנית ל-Windows שנועדה לפתור את אחת הבעיות המתסכלות ביותר בלמידה מרחוק: **חוסר היכולת לקרוא את הלוח של המרצה בזום**.

במקום להתאמץ לפענח טושים דהויים, להסתנוור מהשתקפות של מנורות פלורסנט על הלוח או לראות כתב מטושטש בגלל דחיסת וידאו של הזום — **Qboard מתלבשת כשכבה שקופה ובלתי מורגשת בדיוק מעל חלון הזום** ומשדרגת את הלוח בזמן אמת:

* 🪄 **מנקה השתקפויות ומנורות תקרה:** מנטרלת בוהק פלורסנטים וצללים כבדים על הלוח בעזרת אלגוריתמי פיצוי תאורה מתקדמים (`Specular Glare Compensation`).
* 🖊️ **מחדדת כתב דהוי ונוסחאות עדינות:** משחזרת ומדגישה קווי טוש דקים, חיצים, אינדקסים קטנים וסימני שוויון מבלי להעלים פרטים ומבלי לסתום אותם בכתמי דיו שחורים.
* ⚪ **הופכת את הרקע ללבן חלק וטבעי:** הרקע האפור והעמום של הכיתה הופך ללבן-סורק נקי וקריא, בדומה למסמך סרוק באיכות גבוהה.
* 🖱️ **שקיפות קלט מלאה לזום (`Input Click-Through`):** העכבר והמקלדת עוברים ישירות לזום! **ניתן ללחוץ על רווח כדי לדבר במיקרופון (Push-To-Talk)**, לפתוח את הצ'אט או להפעיל את המחשב כרגיל.
* 👻 **מניעת צילום עצמי (`Anti-Mirror`):** חלון Qboard מוגדר כשקוף ללכידת מסך ברמת Windows DWM (`WDA_EXCLUDEFROMCAPTURE`), כך שהוא לעולם לא נכנס ללולאת השתקפויות אינסופית ("אפקט מנהרה").
* 📸 **צילום סיכום במקש אחד (`F8`):** לחיצה על מקש **`F8`** שומרת צילום חד, נקי ומסונן ברזולוציה מקורית מלאה ישירות לתיקיית `captures/`.

## 💡 מקור השם Qboard

| אות / מילה | משמעות | תפקיד במערכת |
| :---: | :---: | :--- |
| **Q** | **Quality** *(איכות)* | איכות תמונה מקסימלית — חדות דיו, שימור 100% מהקווים והנוסחאות, ועקומת גווני אפור טבעית. |
| **Q** | **Quick** *(מהירות)* | ביצועים קלילים ועיבוד רב-ליבתי מואץ ב-C-SIMD (15–30 FPS) ללא האטה של המחשב. |
| **Board** | **Whiteboard** *(לוח)* | שכבת העצמה והדגשה המתלבשת בדיוק על לוח הכיתה. |

## ✨ תכונות עיקריות

* **מנוע עיבוד V4 (Natural Grayscale Restoration):**  
  מבוסס על גישור סימטרי תת-בלוק (`_sub_macroblock_bridge`), שער צפיפות שכנות `3x3` ללא אובדן דיוק, והרחבת טווח דינמי לגווני ביניים טבעיים.
* **איתור לוח אוטומטי בראייה ממוחשבת (Auto-Board Detection):**  
  זיהוי ממוחשב של מסגרת הלוח בלחיצת כפתור אחת (`Shift + F5` או `Alt + A`).
* **נעילת פינות ידנית (Corner Pinning):**  
  אפשרות לסמן 2 או 4 נקודות של הלוח (`F5`) כדי שהפילטר יעבוד בצורה ממוקדת ומהירה במיוחד רק על אזור הכתיבה.
* **חלון הגדרות צף ומודרני (`F10`):**  
  גישה מהירה ל-5 פרופילים מוכנים (`לוח נקי`, `כתב מודגש`, `טושים צבעוניים`, `לוח כהה Dark Mode`, `ניגודיות טבעית`) ו-7 מחווני כוונון עדינים.

## ⌨️ קיצורי מקלדת גלובליים (פועלים מתוך הזום)

קיצורי המקלדת פועלים ברקע גם כאשר חלון הזום ממוקד:

| מקש קיצור | פעולה | תיאור |
| :--- | :--- | :--- |
| **`F9`** או `Alt + Z` | **הפעלה / כיבוי מהיר** | מציג או מסתיר את שכבת הלוח המשופר מעל הזום |
| **`F10`** או `Alt + O` | **הגדרות וכוונון** | פותח / סוגר חלון הגדרות צף לבחירת פרופילים ומחוונים |
| **`F8`** או `Alt + S` | **צילום ושמירת לוח** | שומר צילום לוח חד ומסונן ברזולוציה מלאה ישירות ל-`captures/` |
| **`F6`** או `Alt + T` | **שקיפות עכבר וקלט** | מעבר בין שקיפות מלאה (דיבור ברווח בזום) למצב עכבר אינטראקטיבי |
| **`F7`** או `Alt + M` | **החלפת מסך** | מעבר נוח בין צגים פיזיים במערך מרובה-מסכים |
| **`F5`** | **סימון פינות הלוח** | נעילת הפילטר על 2 או 4 פינות של הלוח במסך |
| **`Shift + F5`** או `Alt + A` | **זיהוי לוח אוטומטי** | זיהוי ממוחשב של מסגרת הלוח בלחיצת כפתור |
| **`Alt + B`** | **נעיצה מעל חלונות** | מעבר למצב נעוץ תמיד מעל כל החלונות (Always on Top) |
| **`Space`** | **השהיה / המשך** | הקפאת פריים נוכחי להעתקת נוסחאות |
| **`Esc`** | **יציאה / הסתרה** | סגירת חלון ההגדרות או הסתרת השכבה |

## 🚀 התקנה והרצה מהירה

### דרישות מערכת
* **Windows 10 / 11**
* **Python 3.9** ומעלה (עם סימון `Add Python to PATH` בהתקנה)

---

### 🌟 אפשרות א': התקנה אוטומטית בלחיצה כפולה (מומלץ)
פשוט לחצו פעמיים על קובץ ההתקנה:
```cmd
install.bat
```
קובץ ההתקנה מבצע הכל אוטומטית:
1. בודק את תקינות סביבת ה-Python במחשב.
2. מתקין ומעדכן את כל הספריות הנדרשות (`Pillow`, `numpy`).
3. מריץ בדיקה עצמית מלאה (`Self-Test`) לאימות ביצועים ומנוע ה-C-SIMD.
4. יוצר קיצור דרך בשולחן העבודה (`Qboard.lnk`) להפעלה מהירה בלחיצה אחת!

---

### אפשרות ב': התקנה ידנית (למפתחים)
```powershell
pip install -r requirements.txt
python main.py --self-test
```

### הפעלת התוכנה
לאחר ההתקנה, ניתן להפעיל את התוכנה בכל עת:
* בלחיצה כפולה על קיצור הדרך **`Qboard`** בשולחן העבודה.
* או בלחיצה על קובץ ההפעלה:
```cmd
run_qboard.bat
```
* או דרך הטרמינל:
```powershell
python main.py
```

## 📁 מבנה הפרויקט (Project Architecture)

```
Qboard/
├── main.py                 # נקודת כניסה ראשית (הפעלת Qboard או בדיקה עצמית)
├── app.py                  # מנהל השכבה הראשית (QboardApp, Canvas, לולאת רינדור)
├── processor.py            # מנוע עיבוד התמונה V4 (WhiteboardEnhancer, Multi-Core SIMD)
├── capture.py              # מנהל הלכידה (LiveCaptureManager, DWM Window Capture, ROI)
├── tests_runner.py         # חבילת בדיקות אוטומטית מלאה (--self-test)
├── run_qboard.bat          # קובץ הפעלה בלחיצה כפולה למשתמשי Windows
├── requirements.txt        # תלויות פרויקט (numpy, Pillow)
├── .gitignore              # החרגת קובצי ריצה, לוגים וצילומים פרטיים
├── .gitattributes         # הגדרות שורות ותאימות פלטפורמות
├── LICENSE                 # רישיון קוד פתוח MIT
├── captures/               # תיקיית שמירת צילומי לוח (F8)
│   └── .gitkeep
└── ui/                     # חבילת ממשק המשתמש המודולרית
    ├── __init__.py         # ייצוא רכיבי UI
    ├── theme.py            # ערכת נושא Dark Studio, פונטים, צבעים ו-Win32 APIs
    ├── settings_window.py  # חלון הגדרות צף (F10) עם מחוונים ופרופילים
    ├── hotkeys.py          # מנהל קיצורי מקלדת גלובליים (GlobalHotkeyManager)
    └── modals.py           # חלוניות בחירת חלון, בחירת מסך, גזירת אזור וסימון פינות
```
